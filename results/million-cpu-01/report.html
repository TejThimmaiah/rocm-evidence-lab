What this experiment measures

In-memory cosine score matrix computation, concatenation and host dispatch; GPU synchronization included. Excludes embedding, transfer, top-k selection and request queueing.

  • Synthetic normalized vectors; no semantic relevance evaluation.
  • Batch throughput is not individual online request latency.
  • CPU and ROCm use different libraries; compare batching within each backend.
  • No energy, cost, end-to-end RAG, or model-quality claim.

Score tolerance: atol 1e-4, rtol 1e-3. Top-k set agreement must be ≥99%. This checks numerical agreement, not semantic relevance.
